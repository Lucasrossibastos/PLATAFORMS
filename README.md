# PLATAFORMS

Protótipo da plataforma de estudos para vestibular (React, dados de exemplo em memória; Firebase ainda não integrado).

```bash
npm install
npm run dev          # servidor local
npm run build:teste  # gera dist-teste/index.html (arquivo único, usado no ambiente de teste)
```

Logins de teste: `aluno@curso.com` / `123` e `moderador@curso.com` / `123`.
